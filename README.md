# ERP Center CRM

A full-stack Customer Relationship Management application built for ERP Center, Inc. Designed to replace fragmented spreadsheet systems with centralized, production-ready client data infrastructure. Currently in active use.

## 🚀 Features
- **Lead & Account Management:** Comprehensive tools to list, search, and import leads and accounts
- **Opportunity Tracking:** Manage the sales pipeline by tracking potential deals and their progress
- **Sales Logging:** Record and review finalized sales transactions
- **Interaction History:** Log every interaction with customers, including notes and follow-up actions
- **Smart Insights (AI)**
  - *Smart Leads:* AI-powered lead scoring and prioritization
  - *Sales Scripts:* Automated generation of tailored sales scripts based on lead data
- **Authentication:** Secure user signup and login system

## 🛠️ Technical Stack
- **Backend:** Flask (Python)
- **Database:** MySQL with SQLAlchemy ORM (PostgreSQL for production)
- **Frontend:** HTML5, CSS3 (Bootstrap 5), JavaScript
- **AI Integration**: OpenAI API
- **Deployment:** Pre-configured for AWS Elastic Beanstalk

> **Note:** Source code is limited due to client confidentiality.
